# Sổ Chi Tiêu

Ứng dụng web quản lý chi tiêu cá nhân: ghi thu, chi và chuyển khoản giữa các ví, đặt ngân sách theo tháng, xem báo cáo và biểu đồ.

- Dữ liệu lưu trên trình duyệt của từng thiết bị (localStorage), không gửi đi đâu cả.
- Sao lưu và khôi phục bằng file JSON trong mục **Cài đặt**.
- Cài như ứng dụng: trên điện thoại chọn "Thêm vào Màn hình chính", trên máy tính bấm biểu tượng cài đặt trên thanh địa chỉ.
- Dùng được khi không có mạng sau lần mở đầu tiên.

Toàn bộ là file tĩnh (`index.html`, `sw.js`, `manifest.webmanifest`, icon), đăng trực tiếp lên GitHub Pages.
